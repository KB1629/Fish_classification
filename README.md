Fish Species Detection using Deep Learning

📄 Project Overview

This project focuses on developing a high-accuracy fish species detection model using deep learning techniques. Leveraging the power of MobileNetV2, this model achieved an impressive 99.94% accuracy rate in automated image classification.

🚀 Key Features

✅ Utilized MobileNetV2 for efficient and accurate fish species detection.

✅ Achieved an outstanding 99.94% accuracy for image classification.

✅ Applied data augmentation, image preprocessing, and optimized model parameters to improve performance.
